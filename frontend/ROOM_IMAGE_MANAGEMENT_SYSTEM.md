# 📷 ระบบจัดการรูปภาพห้องพัก

## 🎯 สรุปการอัปเดต

เพิ่มความสามารถให้แอดมินสามารถเปลี่ยนรูปห้องพักได้เองจากหลังบ้าน โดยไม่ต้องแก้ไขโค้ดโดยตรง

## ✨ คุณสมบัติหลัก

### 1. 📤 **อัปโหลดรูปภาพ**
- เลือกหลายไฟล์พร้อมกัน
- รองรับ JPG, PNG, GIF
- ตรวจสอบประเภทไฟล์อัตโนมัติ
- สร้างชื่อไฟล์ใหม่ป้องกันชื่อซ้ำ

### 2. 👁️ **ดูตัวอย่าง**
- แสดงรูปปัจจุบันของห้อง
- Preview รูปใหม่ก่อนบันทึก
- แสดงจำนวนรูปทั้งหมด
- ระบุรูปหลัก

### 3. 🗑️ **จัดการรูปภาพ**
- ลบรูปเก่าได้
- เพิ่มรูปใหม่
- เรียงลำดับรูป
- ยกเลิกการเปลี่ยนแปลง

### 4. 🔐 **ความปลอดภัย**
- เฉพาะแอดมินเท่านั้นที่เข้าถึงได้
- ตรวจสอบสิทธิ์การเข้าใช้
- Validation ข้อมูลครบถ้วน

## 🎮 **วิธีการใช้งาน**

### สำหรับแอดมิน:
1. **เข้าระบบ** ด้วยบัญชีแอดมิน
2. **คลิกเมนู** "รูปห้องพัก" ในแดศบอร์ด
3. **เลือกห้อง** ที่ต้องการเปลี่ยนรูป
4. **อัปโหลดรูป** จากเครื่องคอมพิวเตอร์
5. **ดูตัวอย่าง** ก่อนบันทึก
6. **คลิกบันทึก** เพื่อใช้งานจริง

### ขั้นตอนการทำงาน:
```
เลือกห้อง → อัปโหลดรูป → ดู Preview → บันทึก → อัปเดตเว็บไซต์
```

## 📂 **โครงสร้างไฟล์รูปภาพ**

### ชื่อไฟล์ที่สร้างอัตโนมัติ:
```
คู่-1-1727847201-0.jpg
เดี่ยว-2-1727847201-1.png
[ประเภทเตียง]-[ID]-[timestamp]-[index].[extension]
```

### โฟลเดอร์เก็บรูป:
```
public/
└── images/
    └── rooms/
        ├── คู่-1-timestamp-0.jpg
        ├── คู่-1-timestamp-1.jpg
        ├── เดี่ยว-2-timestamp-0.jpg
        └── bathroom-modern.jpg
```

## 🔄 **API Endpoints**

### POST /api/admin/room-images
```javascript
// อัปโหลดรูปภาพใหม่
FormData: {
  images: [File, File, ...],
  roomId: "1",
  roomType: "เตียงคู่"
}

Response: {
  success: true,
  files: ["/images/rooms/...", "..."]
}
```

### PUT /api/admin/rooms
```javascript
// อัปเดตข้อมูลห้อง
{
  id: 1,
  images: ["/path/to/image1.jpg", "..."],
  image_url: "/path/to/main-image.jpg"
}

Response: {
  success: true,
  data: { ...updatedRoom }
}
```
